# Dell Technologies Forum 2026 학습 지도

제품 이름보다 데이터 흐름과 검증 질문을 우선한다.

## 1. 데이터

- 질문: 학습·추론 데이터는 어디서 오고, 품질과 접근 권한은 어떻게 검증하는가?
- 후속 실습: 작은 CSV의 결측치·중복·스키마를 검사하고 처리 전후 행 수를 기록한다.

## 2. 연산

- 질문: CPU·GPU·가속기의 선택이 지연시간·비용·전력에 어떤 영향을 주는가?
- 후속 실습: 같은 추론 작업의 실행 시간과 메모리 사용량을 조건별로 비교한다.

## 3. 저장·네트워크

- 질문: 대용량 데이터가 연산 장치에 병목 없이 도달하도록 어떻게 설계하는가?
- 후속 실습: 파일 크기별 읽기 시간을 반복 측정하고 평균·편차를 표로 남긴다.

## 4. AI 플랫폼

- 질문: 모델 학습·배포·버전·롤백을 어떤 단위로 관리하는가?
- 후속 실습: 모델 버전, 데이터 버전, 지표, 배포 시각을 한 JSON 문서에 연결한다.

## 5. 운영·보안·성과

- 질문: 정확도 외에 안전성·관측성·비용·업무 결과를 어떻게 함께 판단하는가?
- 후속 실습: 오류율·응답시간·비용·사람의 검토 비율을 함께 보는 운영 표를 설계한다.
