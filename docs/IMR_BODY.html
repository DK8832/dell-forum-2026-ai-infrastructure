Dell Technologies Forum 2026 현장 체험과 AI·인프라 기술 탐색

2026년 8월 25일 서울 코엑스에서 열린 Dell Technologies Forum 2026 현장 방문을 계기로, 기업 AI가 실제 서비스로 운영되기 위해 필요한 인프라를 데이터 → 연산 → 저장·네트워크 → AI 플랫폼 → 운영·보안·성과의 다섯 층으로 다시 정리했다.

1. 확인한 사실과 활동 근거

  • 공식·공개 자료 확인: 2026.08.25 09:00~17:30, 서울 코엑스 그랜드볼룸
  • 행사 주제: 가능성, 그 너머의 성과로(From Possibility to Progress)
  • 개인 활동 근거: AIS테크놀러지의 ‘DellTechForum 2026 당사 부스 방문에 감사드립니다’ 메일 제목을 로컬 기록에서 확인

개인정보 보호를 위해 메일 주소와 본문은 공개하지 않았다. 또한 모든 세션 참석이나 특정 장비 성능 측정을 했다고 확대해 쓰지 않았다.

2. 탐색 질문

AI 프로젝트에서 모델 정확도만 보던 관점에서 벗어나 “학습한 모델이 실제 업무에서 계속 작동하려면 무엇이 더 필요한가?”를 질문했다. 제품 이름을 복사하는 대신 입력 데이터부터 운영 결과까지의 연결을 다섯 층으로 나누었다.

  1. 데이터: 출처·품질·접근 권한을 어떻게 검증하는가
  2. 연산: CPU·GPU·가속기를 지연시간·비용·전력 기준으로 어떻게 고르는가
  3. 저장·네트워크: 대용량 데이터 이동 병목을 어떻게 찾는가
  4. AI 플랫폼: 모델·데이터 버전과 배포·롤백을 어떻게 관리하는가
  5. 운영·보안·성과: 오류율·응답시간·비용·사람의 검토를 어떻게 함께 판단하는가

3. 직접 만든 결과물

Python 프로그램이 행사 사실 JSON을 읽어 다섯 층의 질문과 후속 실습을 JSON·Markdown으로 만든다. 같은 내용을 설치 없이 실행되는 인터랙티브 웹 페이지로 구현했다. 카드를 누르면 각 층의 핵심 질문과 다음 측정 실습이 표시된다.

4. 검증 결과

  • 행사 날짜·시간·장소를 공개 출처로 재확인
  • 부스 방문 후속 메일 제목과 열람 시각을 로컬 기록에서 확인
  • 다섯 층 ID 중복 0개, 질문·후속 실습 누락 0개
  • 행사 사실·개인 증빙·사후 학습을 문서에서 구분
  • 자동 테스트 3개 모두 통과

5. 배운 점

AI는 모델 하나가 아니라 데이터의 품질과 이동, 연산 자원, 배포 체계, 보안과 모니터링이 연결된 시스템이라는 점을 배웠다. 현장 체험을 사진이나 제품 목록으로 끝내지 않고, 이해하지 못한 지점을 질문으로 바꾸고 검증 가능한 다음 행동까지 정리해야 학습으로 남는다는 것도 알게 되었다.

6. 한계와 다음 계획

현재 결과물은 공개 자료와 확인 가능한 방문 근거를 바탕으로 만든 사후 학습 지도다. 특정 장비를 직접 벤치마크한 기록은 아니다. 다음에는 작은 AI 파이프라인을 실행해 파일 읽기 시간, 추론 지연, 메모리, 오류율을 측정하고 다섯 층의 질문에 수치로 답할 계획이다.

7. AI 활용 및 공개 자료

행사 정보를 구조화하고 Python 코드·웹 페이지·자동 테스트·문서 초안을 만드는 데 Codex를 활용했다. 참석 여부를 AI가 추정하지 않도록 로컬의 메일 제목을 확인했고 확인되지 않은 세션·제품·성과는 넣지 않았다.
