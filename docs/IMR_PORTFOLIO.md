# Dell Technologies Forum 2026 현장 체험과 AI·인프라 기술 탐색

## 1. 활동 개요

2026년 8월 25일 서울 코엑스 그랜드볼룸에서 열린 Dell Technologies Forum 2026을 계기로 기업 AI가 실제 서비스로 운영되기 위해 필요한 인프라를 정리했다. 행사 주제는 ‘가능성, 그 너머의 성과로(From Possibility to Progress)’였고, 공식 안내에서 지능형 디바이스·모던 인프라·AI 전문 지식을 주요 영역으로 제시했다.

현장 방문 사실은 AIS테크놀러지가 9월 1일 보낸 `DellTechForum 2026 당사 부스 방문에 감사드립니다`라는 메일 제목이 로컬 브라우저 기록에 남아 있는 것으로 확인했다. 개인정보 보호를 위해 메일 주소와 본문은 공개 첨부에 포함하지 않았다.

## 2. 탐색 질문

AI 프로젝트를 하며 주로 모델과 정확도에 집중했지만, 현장 행사를 계기로 “학습한 모델이 실제 업무에서 지속적으로 작동하려면 무엇이 더 필요한가?”라는 질문을 세웠다. 특정 제품 이름을 나열하는 대신 데이터가 들어와 결과가 나가기까지의 흐름을 다섯 층으로 나누었다.

1. 데이터: 출처·품질·권한을 어떻게 확인하는가
2. 연산: CPU·GPU·가속기를 어떤 기준으로 선택하는가
3. 저장·네트워크: 데이터 이동 병목을 어떻게 찾는가
4. AI 플랫폼: 모델·데이터 버전과 배포·롤백을 어떻게 관리하는가
5. 운영·보안·성과: 오류율·지연시간·비용·사람 검토를 어떻게 함께 보는가

## 3. 결과물

`build_learning_map.py`는 행사 사실 JSON을 읽고 다섯 층의 핵심 질문과 후속 실습을 JSON·Markdown으로 생성한다. 같은 내용을 `index.html`에서 카드형 인터랙티브 학습 지도로 구현했다. 페이지를 더블클릭해 실행할 수 있고, 각 층을 누르면 핵심 질문과 다음에 직접 측정할 실습이 표시된다.

## 4. 검증

- 공식·공개 자료에서 날짜 2026-08-25, 시간 09:00~17:30, 장소 서울 코엑스 그랜드볼룸을 재확인했다.
- 로컬 브라우저 기록에서 부스 방문 후속 메일 제목과 2026-09-01 열람 기록을 확인했다.
- 다섯 층의 ID 중복, 질문·실습 누락, 행사 날짜·장소를 자동 테스트 3개로 검사했다.
- 공개 자료와 개인 활동 근거, 행사 후 재구성한 학습 내용을 문서에서 각각 표시했다.

## 5. 배운 점

AI는 모델 하나가 아니라 데이터의 품질과 이동, 연산 자원, 배포 체계, 보안과 모니터링이 연결된 시스템이라는 점을 배웠다. 또한 행사 참여 기록은 “무엇을 보았다”에서 끝나지 않고, 내가 이해하지 못한 지점을 질문으로 바꾸고 검증 가능한 다음 행동을 정해야 학습으로 남는다는 점을 알게 되었다.

## 6. 한계와 다음 계획

현장에서 모든 세션에 참석했거나 특정 장비의 성능을 직접 측정했다고 주장하지 않는다. 현재 결과물은 공개 자료와 확인 가능한 방문 근거를 바탕으로 만든 사후 학습 지도다. 다음에는 작은 AI 파이프라인을 직접 실행하며 파일 읽기 시간, 추론 지연, 메모리, 오류율을 측정하고 다섯 층의 질문에 수치로 답할 계획이다.

## 7. AI 활용 범위

공개 행사 정보를 구조화하고, 학습 지도를 생성하는 Python 코드·웹 페이지·자동 테스트·문서 초안을 만드는 데 Codex를 활용했다. 참석 여부를 AI가 추정하지 않도록 로컬 기록의 메일 제목을 별도로 확인했고, 확인되지 않은 세션 참석·제품 조작·성과 수치는 넣지 않았다.
